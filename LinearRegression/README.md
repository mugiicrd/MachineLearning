# Salary Prediction Using Linear Regression
This project uses machine learning and Linear Regression to predict 
salaries based on years of professional experience.


# Technologies Used
- Python
- Pandas
- Numpy
- scikit-learn
- Matplotlib

# Features
- data exploration
- Linear Regression model
- training and testing data
- Model evaluation
- interactive salary prediction

# How it works
1. Load the salary dataset
2. Seperate the independent variable(yearsExperience) from the target
variable(Salary)
3. Split the data into training and testing data
4. Train a Linear Regression model
5. Evaluate the model's performance
6. Allow users to predict salaries using new experience values

# Results
Model performance metrics and visualizations will be displayed
when running the program
